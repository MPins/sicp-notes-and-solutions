# SICP Notes and Solutions

My public learning journal while reading **Structure and Interpretation of Computer Programs (SICP)**.

This repository contains my notes, exercise solutions, experiments, and reflections as I work through the book. The goal is not only to solve exercises, but to better understand the ideas behind abstraction, programming languages, state, modularity, and system design.

## Why SICP?

SICP remains one of the most influential books in computer science.
I'm reading it to strengthen fundamentals that apply far beyond Scheme:

* Functional programming
* Abstraction and composition
* State and mutation
* Interpreters and evaluators
* Streams and delayed computation
* Building complex systems from simple primitives

## About This Repository

The idea of sharing my notes and solutions publicly came only after I had already reached **Chapter 3**.

Because of that:

* I was able to recover some saved solutions from **Chapter 2**
